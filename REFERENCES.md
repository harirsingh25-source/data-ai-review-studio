## Classroom review design

The recurring review pattern is:

```text
central question
      ↓
predict
      ↓
interactive experiment
      ↓
evidence returned
      ↓
decision
      ↓
hint / reveal
      ↓
final mystery
      ↓
Python code companion
```

This intentionally mirrors the structure of the SQL Dinner-Party Mystery while keeping each new review scientifically appropriate to its topic.
